## 目标

新增齿轮的批量合成配方生成。配方为十字形有序合成（**不消耗锤**）：

```
[ ]  [板]  [ ]
[杆] [锭]  [杆]
[ ]  [板]  [ ]
```

即同一材料的 板×2 + 杆×2 + 锭×1 → 齿轮×1。板/杆使用本模组批量注册的对应材料中间产物。

## 修改内容

### 1. `BatchMaterialRegistrar.java` 新增 `generateGearRecipe(MaterialConfig)`

沿用现有板/杆生成器的结构（`writeRecipeJson` 写入 src + build 目录，`ingotItem` 为 null 的材料跳过）：

```json
{
  "type": "minecraft:crafting_shaped",
  "pattern": [" P ", "RIR", " P "],
  "key": {
    "P": { "item": "starcore_forge:<材料>_plate" },
    "R": { "item": "starcore_forge:<材料>_rod" },
    "I": { "item": "<对应锭，如 minecraft:iron_ingot>" }
  },
  "result": { "id": "starcore_forge:<材料>_gear", "count": 1 }
}
```

配方 ID：`<材料>_gear_from_plate_and_rod`。图案空位用空格（原版规则）。

### 2. `registerAllBuiltIn()` 追加调用

在 `generateRodRecipe(material)` 后调用 `generateGearRecipe(material)`，将来新增材料自动获得齿轮配方。

### 3. 手写 5 个齿轮配方 JSON

`src/main/resources/data/starcore_forge/recipe/` 下新增 iron/gold/copper/netherite/starcore 五个 `*_gear_from_plate_and_rod.json`，与生成器输出逐字节一致。

## 验证

- `./gradlew compileJava` 编译通过。
- PowerShell 校验 15 个配方 JSON（10 旧 + 5 新）语法与图案。
- 启动游戏确认 15 个配方无解析错误，可用 EMI 查看齿轮配方摆放预览。
