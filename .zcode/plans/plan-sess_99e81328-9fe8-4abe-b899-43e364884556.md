## 诊断结论：板配方失败的根因

游戏实际加载的板配方（`crafting_shaped` 竖列 `H/I/I`）本身是**正确的**，问题在于**配方冲突**：

- 杆配方目前是**无序合成**（crafting_shapeless），材料组合与板配方完全相同（锤 + 锭 + 锭）。
- 无序配方无视位置——竖着摆放（锤在上、锭在下）时，杆配方和板配方**同时匹配**。
- 游戏对同一摆放只取一个匹配结果，杆配方胜出，所以板永远合不出来。

## 修复方案（杆配方改对角有序，冲突自然消除）

### 1. `BatchMaterialRegistrar.generateRodRecipe()` 改为对角有序配方

按你的规格：**左上角 = 锤，正中 = 锭，右下角 = 锭**，产出杆×2：

```json
{
  "type": "minecraft:crafting_shaped",
  "pattern": ["H..", ".I.", "..I"],
  "key": { "H": "锤", "I": "对应锭" },
  "result": { "id": "..._rod", "count": 2 }
}
```

模式占满 3×3，位置完全固定（无序→有序后不再与板配方冲突：竖列只匹配板、对角只匹配杆）。方法注释同步更新。`registerAllBuiltIn()` 已在上次接入了 `generateRodRecipe()` 调用，无需再改调用点。

### 2. 重写 5 个杆配方 JSON（`*_rod_from_hammer.json`）

手写为与生成器输出完全一致的对角 shaped 格式（iron/gold/copper/netherite/starcore），无需运行游戏仓库里即为正确状态。

### 3. 板配方不动

板配方保持竖列 `H/I/I`（锭在锤正下方）不变——冲突消除后即可正常合成。
