## 目标

新增"锤锻粉"批量配方：竖向 1×2 有序合成——**上为锤、下为锭 → 对应粉 ×1**（如 铁锭 → 铁粉）。

- 模式 `"H" / "I"`，锭必须严格在锤子正下方（可在任意列平移）。
- 与现有配方无冲突：板是 3 格竖列、杆是对角 3×3、粉只有 2 格，材料数量不同不会互相匹配。
- 只有 2 格高，随身 2×2 合成格也能合成。

## 修改内容

### 1. `BatchMaterialRegistrar.java` 新增 `generateDustRecipe(MaterialConfig)`

沿用板/杆/齿轮生成器结构（`writeRecipeJson` 写 src+build，`ingotItem` 为 null 的材料跳过）：

```json
{
  "type": "minecraft:crafting_shaped",
  "pattern": ["H", "I"],
  "key": { "H": "锤", "I": "对应锭" },
  "result": { "id": "starcore_forge:<材料>_dust", "count": 1 }
}
```

配方 ID：`<材料>_dust_from_hammer`。粉物品本身已随 `MaterialVariantType.values()` 注册，只缺配方。

### 2. `registerAllBuiltIn()` 追加调用

顺序变为 板 → 杆 → 齿轮 → 粉，新材料自动获得全部四种配方。

### 3. 手写 5 个粉配方 JSON

新增 iron/gold/copper/netherite/starcore 的 `*_dust_from_hammer.json`，与生成器输出逐字节一致。

## 验证

- `./gradlew compileJava` 编译通过。
- PowerShell 校验 20 个配方 JSON。
- 启动游戏确认 20 个配方 0 解析错误，可在随身 2×2 格用"锤上锭下"合成粉。
